# Dataset Selection

AegisAI uses the NSL-KDD dataset for training and evaluating the intrusion
detection models.

## Why NSL-KDD
- Widely used in IDS research
- Balanced dataset
- Contains both normal and attack traffic
- Suitable for supervised and anomaly-based learning

## Data Characteristics
The dataset includes features such as protocol type, service, flag,
source bytes, destination bytes, and attack labels.
